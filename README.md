# ask.so

MCP-Server fuer Solothurner Regierungsratsbeschluesse (RRB).

Aktuelle MCP-Funktionen:

- `get_rrb_pdf` fuer Original-PDF, PDF-Link und PDF-Resource
- `get_rrb_text` fuer Text-Extraktion, Zusammenfassung und Analyse

Ausfuehrliche MCP-Dokumentation mit JSON-Beispielen und Mermaid-Diagrammen:

- [docs/mcp-tools.md](docs/mcp-tools.md)
